One line roasting an alarm clock that rings at 6 AM on a Saturday.

Bounty: https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6

## Entry

`main.py` (pure Python stdlib, no dependencies) writes one roast line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> My alarm clock screams at 6 AM on a Saturday with the urgency of a fire alarm and the importance of an expired coupon.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
